# Campaign Brief: depswiz

## Core Message
Stop playing dependency whack-a-mole across your polyglot stack - get ONE dashboard for Python, Rust, React, and Flutter vulnerabilities.

## Target Audience
- **Who:** Full-stack developers and DevOps engineers managing 3+ language codebases (Python backend + JS frontend + mobile/systems components)
- **Where:** Dev Twitter, r/programming, r/devops, Hacker News, engineering Slack communities, GitHub
- **Their pain:** Spending hours context-switching between npm audit, cargo audit, pip-audit, dart pub deps every time a CVE drops

## Main Angles
1. **Problem Angle:** "Tuesday: Critical CVE drops. You: Running 4 different audit tools, cross-referencing databases, trying to remember which service uses which package manager. 2 hours later, you finally know what's broken."

2. **Solution Angle:** "`depswiz check` → unified dashboard → 73% → 89% → 94% health score as you patch across languages. One command, complete visibility."

3. **Story Angle:** "The vulnerability you missed wasn't in your Python backend or React frontend. It was in that Flutter dependency you forgot about. depswiz would have caught it."

## Tone
Technical, frustrated

## Platform Strategy
- **Primary:** Dev Twitter (where security discussions happen fast)
- **Secondary:** r/programming and Hacker News (for deeper technical discussion)

## Absolutely avoid
- Generic "developer productivity" messaging
- Claiming it replaces language-specific tools entirely
- Overselling the AI features over core functionality
- Making it sound like just another security scanner
